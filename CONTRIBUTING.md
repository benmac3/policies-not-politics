# Contributing

Critique is welcome. Use an issue for a data correction, source challenge, definition problem or competing model. State the claim/series ID, date, unit, source URL and proposed correction. Include code and expected output where relevant.

For a model change, explain the mechanism, counterfactual, assumptions, sensitivity and what evidence could falsify it. Apply the same standards to every party. Separate facts, official projections, party claims and your estimates. Preserve historical data vintages and document revisions.

Do not post personal data about participants, providers or private individuals. Named fraud allegations need primary records and precise legal status; disputes over policy are welcome, personal abuse is not. Public career records should be factual and relevant.

Before submitting: run the build, validation and model checks listed in README.md. Add a changelog entry, provide source provenance, and explain any effects on displayed conclusions. Do not edit generated browser data without updating the source JSON.
